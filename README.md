# JJWXC for KOReader

一个非官方的 KOReader 晋江文学城阅读插件，适合在 Kobo 等设备上阅读自己有权访问的晋江作品。

插件提供书架、章节目录、免费章与已购 VIP 正文、段评缓存、离线 EPUB，以及 Simple UI 快捷操作。当前主要针对 **Kobo + KOReader + Simple UI** 调整。

> 本项目与晋江文学城、KOReader 官方均无隶属、合作或背书关系。请遵守晋江文学城服务条款及当地法律。不要传播付费正文、段评缓存、登录凭证或生成的离线书籍。

## 主要功能

- 登录晋江账号，支持登录验证流程。
- 查看个人书架、作品信息和章节目录。
- 阅读免费章节和当前账号已经购买的 VIP 章节。
- 每部小说只使用一个稳定 HTML 文件，避免首页出现大量单章书籍。
- 到达章末自动进入下一章，在章节第一页向前翻可进入上一章。
- 正文段落末尾显示段评数量，点击数字打开段评窗口。
- 按章或按整本下载段评，下载后可以离线查看。
- 可选“自动预载下一章段评”，一边阅读一边积累本地缓存。
- 下载全部免费章和已购章，并生成带封面和目录的离线 EPUB。
- 正文与段评任务可以暂停、继续和停止，并自动跳过有效缓存。
- 注册为标准 KOReader 插件和阅读动作；Simple UI 集成失败时主插件仍可使用。

## 安装与升级

1. 从 GitHub Releases 下载最新 ZIP。
2. 解压后得到 `jjwxc.koplugin` 文件夹。
3. 将整个文件夹复制到 KOReader 的 `plugins` 目录：

   ```text
   koreader/plugins/jjwxc.koplugin/_meta.lua
   koreader/plugins/jjwxc.koplugin/main.lua
   ```

4. 完全退出并重新启动 KOReader。
5. 从工具菜单打开“★ 晋江文学城”。

升级时直接用新版 `jjwxc.koplugin` 覆盖旧文件夹，然后重启 KOReader。不要在 `plugins` 中额外嵌套版本号目录。

插件更新不会主动删除账号设置、阅读进度、正文缓存和段评缓存。

## 快速开始

### 登录并开始阅读

1. 打开“★ 晋江文学城”。
2. 选择“登录晋江”，按提示完成登录。
3. 打开“我的书架”，选择作品和章节。
4. 插件只会尝试读取免费章节和当前账号已经购买的章节。

插件不能代替用户购买新章节。请在晋江官方 App 或网站完成购买，然后在插件中选择“刷新目录 / 购买状态”。

### 在线 HTML 模式

HTML 是目前推荐的段评阅读模式：

- 每部小说只有一个稳定 HTML 文件。
- 换章时复用同一个文件，不会在首页产生单章书籍。
- 已缓存段评会显示为正文后的下划线数字。
- 点击数字打开插件自己的段评窗口，关闭后仍停留在原章节。
- 已缓存正文和段评可以离线读取；尚未缓存的内容仍需联网。

### 离线 EPUB 模式

先运行“下载本书全部可读章节”，任务会保存所有免费章和已购章，并生成 `_离线版.epub`。

EPUB 适合使用 KOReader 的原生功能：

- 完整目录
- 封面与书籍信息
- 书签、高亮、搜索和阅读统计
- 无网络连续阅读已缓存章节

段评会尽量写入 EPUB，但不同 KOReader/CREngine 版本对脚注链接和弹窗的处理并不完全一致。如果 EPUB 中的段评排版或点击效果不理想，请使用 HTML 模式查看段评；本地段评缓存不会因此丢失。

更新插件不会自动改写已经生成的 EPUB。涉及 EPUB 结构的更新，需要关闭 EPUB，运行“生成 / 更新离线 EPUB”，再重新打开。

## 段评下载与缓存

### 下载本章段评

在 HTML 正文中选择“下载 / 刷新本章离线段评”。成功后，评论会保存到 Kobo 本地，并刷新本章的段评数字。

该功能也注册为 KOReader 阅读动作和 Simple UI Quick Action，可以映射到手势、实体按键或蓝牙翻页器。

### 下载整本段评

整本正文与整本段评是两个独立任务：

1. 先运行“下载本书全部可读章节”。
2. 再运行“下载本书全部段评”。

整本段评只处理已经缓存正文的章节。有效缓存会跳过；旧版产生的 0 条空缓存会重新下载。网络临时错误最多补试一次，仍失败就记录并继续下一章，不会无限等待。

长篇作品可能有成千上万次段评请求，所以整本段评通常比正文慢很多。插件不会高并发请求，以减少设备负担和账号限流风险。

### 自动预载下一章段评

在 HTML 阅读时，可从晋江菜单勾选“自动预载下一章段评”。

- 默认关闭，由用户主动开启。
- 每次只处理下一章，不会自动连续下载整本。
- 在独立后台进程中运行，不锁住翻页和点击。
- 已有有效缓存时不联网、不重复下载。
- 预载成功后永久保存在本地，退出 KOReader、重启设备或断网后仍可使用。
- 关闭开关会停止尚未完成的自动预载。
- 完成时不会自动重建当前 HTML，避免电子墨水屏闪烁、跳页或位置变化。

如果你在预载完成前已经进入下一章，本次可能暂时看不到新数字。稍后重新打开该章，或选择“从缓存重建本章段评标记”即可。

自动预载会短暂使用 Wi-Fi 和处理器，但一次只下载一章，耗电明显低于整本段评下载。

### 离线查看段评

段评第一次下载需要网络。保存成功后：

- HTML 模式可以离线打开段评窗口。
- 重新生成 EPUB 时会读取同一份本地段评缓存。
- 再次运行下载任务会跳过已有的有效缓存。

卸载插件程序不会自动删除缓存。只有手动删除 JJWXC 数据目录时，正文、段评和 EPUB 才会消失。

## Simple UI

插件会优先注册为标准 KOReader 插件，因此即使 Simple UI 集成加载失败，仍可从 KOReader 工具菜单使用“★ 晋江文学城”。

支持相应 Quick Action 的 Simple UI 版本可以添加：

- 晋江书架
- 当前小说目录
- 上一章 / 下一章
- 下载本章离线段评
- 下载整本正文
- 下载整本段评
- 生成或打开离线 EPUB

如果 Simple UI 的插件列表中暂时没有晋江，先确认标准工具菜单能够打开插件，并在覆盖插件后完整重启 KOReader。

## 常见问题

### HTML 有段评缓存，但正文没有数字

选择“从缓存重建本章段评标记”。该操作不联网，会重新按段落编号和引用原文匹配评论，并显示缓存评论数及成功匹配的段落数。

### 错误提示“本章第 21 段下载失败”是什么意思

它指当前章节里编号为 21 的段落请求失败，不是第 21 章。为了避免保存残缺数据，只要一段下载失败，当前整章就不会写入新的段评缓存，并在整本任务中计为失败一章。下次重新运行时仍会尝试这一章。

### 为什么整本段评很快结束

如果章节已经存在有效缓存，插件会直接跳过。进度与完成提示会显示已缓存章节、空缓存重试数、评论总数和失败章节。

### 为什么下载很慢

插件需要先读取每章段评索引，再按有段评的段落分页获取评论。评论很多的长篇作品可能产生大量串行请求。任务可以暂停、继续或停止，已经成功保存的章节不会重下。

### 为什么 EPUB 段评和 HTML 看起来不同

HTML 段评由插件自己的 KOReader 窗口显示；EPUB 段评依赖阅读引擎处理书内链接和脚注。不同 KOReader 版本的行为可能不同，因此需要稳定查看段评时建议使用 HTML，EPUB 则主要用于连续离线阅读和原生书籍功能。

### 下一章为什么从中间或末页打开

插件换章时会清理稳定 HTML 的旧阅读位置，并将新章节定位到第一页。若仍出现错误位置，请提供 KOReader 版本、插件版本和可复现步骤。

### 购买新章节后怎么更新

在晋江官方 App 或网站购买，然后回到插件选择“刷新目录 / 购买状态”。插件不会自动购买，也不会绕过阅读权限。

## 本地数据与隐私

- 密码只用于当次登录请求，不会写入插件设置文件。
- 登录成功后，账号名和 Token 会明文保存在设备的 KOReader 设置目录。
- 正文、段评、封面、下载状态和 EPUB 均保存在用户设备本地。
- 请勿上传或分享设置文件、调试包、缓存目录或生成的 EPUB。
- 提交截图和日志前，请遮盖账号、Token、设备序列号、MAC 地址及小说正文。

详见 [SECURITY.md](SECURITY.md) 与 [PRIVACY.md](PRIVACY.md)。

## 兼容性与限制

- 当前版本：`0.4.57`
- 目标环境：支持 Lua 5.1 的近期 KOReader
- 重点测试环境：Kobo + Simple UI
- 其他 KOReader 设备尚未完整验证，欢迎反馈
- 晋江接口并非公开稳定 API，可能调整、限流或停止工作
- 插件只读取当前账号有权访问的内容，不购买章节、不绕过权限
- 批量段评明显比普通阅读更耗时、耗电和网络流量
