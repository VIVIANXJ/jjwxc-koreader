# JJWXC for KOReader

一个非官方的 KOReader 晋江文学城阅读插件，面向拥有合法晋江账号和阅读权限的用户。

> 本项目与晋江文学城及 KOReader 官方均无隶属、合作或背书关系。请遵守晋江文学城的服务条款及当地法律，不要传播付费正文、段评缓存、登录凭证或其他受版权保护的数据。

## 当前功能

- 晋江账号登录及验证码流程
- 查看个人书架、作品信息和完整章节目录
- 阅读免费章节及账号已经购买的 VIP 章节
- 每部小说使用一个稳定的在线 HTML 文件，避免首页出现大量单章书籍
- 正文段落末尾显示段评数量，轻点数字以弹窗查看段评
- 本章段评缓存，以及与正文分开的整本段评下载任务
- 下载全部免费章和已购章，并生成带目录与封面的离线 EPUB
- 正文与段评批量任务均可暂停、继续和停止，已有缓存会自动跳过
- KOReader 标准插件菜单、动作与手势入口
- 可选的 Simple UI 快捷操作集成

## 安装

1. 从 Releases 下载 ZIP，并解压得到 `jjwxc.koplugin` 文件夹。
2. 将整个文件夹复制到 KOReader 的 `plugins` 目录，使最终结构为：

   ```text
   koreader/plugins/jjwxc.koplugin/_meta.lua
   koreader/plugins/jjwxc.koplugin/main.lua
   ```

3. 完全退出并重新启动 KOReader。
4. 在 KOReader 的工具菜单中打开“★ 晋江文学城”。

不要在 `plugins` 目录中额外嵌套一层版本号文件夹。

## 使用建议

### 在线阅读

登录后打开“我的书架”，选择作品和章节。插件只会尝试读取免费章节以及当前账号有权阅读的已购章节。

### 离线正文与 EPUB

先选择“下载本书全部可读章节”。任务完成后会生成或更新离线 EPUB。重新运行会跳过已经保存的正文。

### 离线段评

整本段评与正文是两个独立任务：

1. 先下载整本正文。
2. 再选择“下载本书全部段评”。

段评任务只处理已经成功缓存正文的章节，并自动跳过已有段评缓存。任务完成后会自动重建同一个离线 EPUB，并立即刷新当前打开的 HTML 章节：有段评的正文末尾显示下划线数字，轻点后以 EPUB 脚注弹窗查看。段评也继续保存在插件数据目录中，供 HTML 在线阅读版使用。

### 段评常见问题

**为什么打开或切换章节后没有立即出现段评数字？**

从 `0.4.37` 开始，插件不再在每次打开章节时自动下载整章段评。此前的自动请求会阻塞界面，造成翻页和换章卡顿。请在联网时手动选择“下载 / 刷新本章离线段评”，或运行“下载本书全部段评”。已经保存过的章节会直接使用本地缓存显示数字。`0.4.39` 起，本章段评保存后会原地刷新正文并保留当前页，无需退出重进。

`0.4.42` 修复了晋江原始 `paragraph_id` 与 HTML 排版段落号不一致导致的“缓存有段评但正文没有数字”。已有缓存会在打开 HTML 或重新生成 EPUB 时按引用原文重新匹配，不需要重新下载。

如果 HTML 仍未出现数字，请在该章正文中选择“从缓存重建本章段评标记”。完成提示会显示缓存评论数和成功匹配段落数；该动作不联网，也不会重复下载。

“下载本章离线段评”已注册为 Simple UI Quick Action 和 KOReader 阅读动作，可加入快捷按钮，也可通过 KOReader 的按键、手势或配置文件映射给蓝牙遥控器。该动作需要在晋江在线 HTML 正文中执行。

`0.4.40` 起，整本段评任务遇到 DNS、断网或超时会自动暂停在当前章；网络恢复后点“继续”会重试同一章。已经缓存成功的章节不会重复下载。

`0.4.48` 起，旧版本错误保存的0条空缓存不会再被当成已完成。重新运行整本段评任务即可自动重试这些章节；真正含有评论的有效缓存仍会跳过。

`0.4.49` 起，慢网络下的 `HTTP wantread/wantwrite` 会自动补试1次。补试后仍失败就记录并继续下一章，不会无限等待；下次重新运行整本段评时会再试失败章。

`0.4.50` 起，EPUB 的段评作为非线性脚注内嵌在对应章节中。轻点段落后的数字应由 KOReader 使用脚注弹窗显示，而不是跳到独立的整页段评文档。安装新版后需要重建离线 EPUB，旧 EPUB 不会自动改变。

`0.4.51` 修复部分 KOReader/CREngine 版本仍把内嵌脚注排入正文、导致章节末尾展开全部段评的问题。脚注内容从正常排版隐藏，但仍保留为数字链接的弹窗目标。

`0.4.52` 起，当晋江插件正常加载时，离线 EPUB 的段评数字不再依赖 KOReader 默认脚注弹窗样式。插件会直接从本地段评缓存打开与 HTML 模式相同的窗口，包括原文、作者、时间、赞数、评论和回复。安装后需重建离线 EPUB，使数字链接包含新的章节标识。

在线 HTML 阅读时，翻过章节最后一页会进入下一章；在章节第一页继续向前翻会进入上一章末页。该行为适用于屏幕点击、滑动、手势和设备实体翻页键。

**查看段评必须联网吗？**

第一次下载需要联网。保存成功后，HTML 阅读版可以离线打开段评弹窗；重新生成的离线 EPUB 也会包含已缓存段评，无需联网。

**为什么整本段评下载很慢？**

晋江的段评需要先读取每章的段落索引，再按有段评的段落分页请求。长篇作品可能产生数千次网络请求，耗时明显高于正文下载。任务可以暂停、继续或停止，已经完成的章节不会重复下载。为降低账号限流风险，插件不会大量并发请求。

**为什么段评任务窗口很快消失？**

如果相关章节已经存在本地段评缓存，插件会跳过网络下载并直接重建 EPUB，因此任务可能很快结束。完成提示会显示缓存章节、评论总数、失败章节以及 EPUB 更新结果。

**为什么 EPUB 中没有段评，或者点击数字只会翻页？**

请先下载正文，再运行“下载本书全部段评”或手动更新本章段评。段评任务完成后会更新同一个 `_离线版.epub`。如果 EPUB 当时正在打开，请关闭后重新打开，让 KOReader 读取更新后的文件。

EPUB 中的下划线数字使用标准脚注链接。请在 KOReader 的链接设置中开启“轻点打开链接”和“脚注以弹窗显示”（不同版本的译名可能略有差异）。如果轻点位置没有落在数字链接上，KOReader 会把它当成普通翻页；`0.4.38` 已扩大数字的有效点击区域。`0.4.43` 起每个段落使用独立脚注文件，轻点数字只显示该段段评，不会把全章段评合并进同一弹窗。

**正文和段评必须一起下载吗？**

不必。正文和段评是两个独立任务。只需要离线阅读正文时，可以完全不下载段评；需要段评时再按章或按整本补充缓存。

### Simple UI

插件即使无法加载 Simple UI 集成，也会继续出现在 KOReader 标准插件菜单。Simple UI 版本支持快捷操作注册时，可以把“晋江书架”“晋江目录”“下载整本正文”“下载整本段评”等动作加入快捷区。

## 隐私与本地数据

- 密码只在登录请求期间使用，插件不会把密码写入设置文件。
- 登录成功后，晋江账号名和 Token 会明文保存在设备的 KOReader 设置目录中。
- 下载的正文、段评缓存、封面和 EPUB 均保存在用户设备本地。
- 请勿上传或分享 KOReader 设置、调试包、缓存目录及生成的 EPUB。
- 卸载插件文件不会自动删除设置和下载数据。

详见 [SECURITY.md](SECURITY.md) 与 [PRIVACY.md](PRIVACY.md)。

## 兼容性与限制

- 当前版本：`0.4.52`
- 目标运行环境：支持 Lua 5.1 的近期 KOReader
- 已针对 Kobo + Simple UI 的使用方式设计；其他 KOReader 设备欢迎反馈
- 晋江接口属于非公开接口，可能随时调整、限流或停止工作
- 批量下载段评会产生大量网络请求，耗时和耗电均明显高于普通阅读
- 打开或切换章节不会再自动下载整章段评；请使用本章或整本段评下载命令按需缓存
- 插件不会购买新章节；请在晋江官方 App 或网站完成购买，再刷新目录和购买状态
- 断网或在线目录读取失败时，会使用整本下载保存的离线目录；未缓存章节仍无法离线打开

## 开发与打包

源码位于 `plugins/jjwxc.koplugin/`。本地检查并打包：

```sh
./scripts/check.sh
./scripts/package.sh
```

生成文件位于 `dist/`。提交改动前请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。
